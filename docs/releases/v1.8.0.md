## 📦 更新方式

已安装用户：**系统设置 → 网页更新 → 稳定版 → 检查更新**。

新用户：

```bash
curl -fsSL https://raw.githubusercontent.com/cshaizhihao/OU-YAML/main/install.sh | sudo bash
```

原数据和订阅地址保留，无新增数据库迁移。更新前仍建议备份整个 `data` 目录，包括 `subscription.key`。已保存的高级方案可从卡片直接再次编辑。

来源更新失败时旧内容仍在，但节点是否可用取决于实际网络和上游服务。修改规则后，记得检查发布，再在客户端刷新订阅。
