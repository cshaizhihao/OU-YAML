# 💜 OU-YAML v2.0.0

**更可靠地编辑订阅，更直观地管理策略组。**

- 🛠️ 未知 API 返回明确 JSON 错误；前端识别服务器返回的 HTML/非 JSON 响应，避免 JSON 解析异常掩盖原因。
- ✏️ 已生成订阅加载、保存、重试和重新载入状态更清楚；未发布的编辑不会被失败重试悄悄覆盖。
- 🧩 策略组总览显示全部组，清楚区分组排序与组嵌套；移动端支持触摸拖放和明确的分区入口。
- 🏳️ 国旗成为节点名称的真实前缀，名称更新保持幂等并同步配置引用，不会只添加装饰图标或自动发布订阅。
- 🔗 节点库明确标记复制节点协议链接；TCP 端口探测与代理实测分别呈现。
- 🎨 清理历史样式覆盖，按设计 Token 和页面模块整理 CSS，保持紫色 Liquid Glass 的同时提高文字对比度。
- 🧭 新手主流程继续围绕导入、配置、发布，分组与规则说明和实际操作一致。
- ♻️ 加强交互式安装、反向代理/端口冲突检查、升级前备份、健康检查与失败回滚。

## 🔄 更新方式

已安装用户：**系统设置 → 网页更新 → 稳定版 → 检查更新**。

新用户使用具备 `sudo` 权限的交互式 SSH 终端：

```bash
curl -fsSL https://raw.githubusercontent.com/cshaizhihao/OU-YAML/main/install.sh | sudo bash
```

升级前请下载应用数据备份。常规配置更新保留原订阅地址；发布新内容后，请在客户端刷新订阅。

TCP 探测仅说明服务器端口是否可连接，不代表代理认证、转发和客户端网络均可用。
