# 💎 OU-YAML v2.0.1

**全新 UI 重构：Cyber Obsidian Glassmorphism 现代科技美学与极致丝滑交互。**

- 🎨 **视觉系统全面革新**：彻底告别陈旧脏紫泥色与刺眼白色色块，全线升级为深曜石纯黑背景（`#08090e`）、电光紫蓝（`Electric Indigo`）、赛博天青（`Cyber Cyan`）与晶体毛玻璃层次。
- ✨ **微光边框与动态呼吸感**：面板、卡片、侧边栏采用纳米级内发光（Inner Glow）与 20px 高透光高斯模糊，核心状态带有动态呼吸光晕。
- ⚡ **丝滑物理反馈**：按钮全局采用 Spring 物理弹性按压触感（`scale(0.975)`）与悬停微浮（Hover Lift）。
- 🧭 **侧边栏与顶栏升级**：发光渐变指示条激活态、发光 Logo 光环、悬浮毛玻璃顶栏与优雅状态脉冲灯。
- 🧩 **看板与拖拽交互**：策略组看板泳道采用柔和赛博青蓝脉冲环，消除拖拽闪烁与白色断层；抽屉与弹窗支持弹性平滑展开。
- 📱 **暗夜科技登录与向导**：全屏科技代码背景登录页，高质感深空黑曜石向导弹窗与发光光圈。

## 🔄 更新方式

已安装用户：**系统设置 → 网页更新 → 稳定版 → 检查更新**。

新用户使用具备 `sudo` 权限的交互式 SSH 终端：

```bash
curl -fsSL https://raw.githubusercontent.com/cshaizhihao/OU-YAML/main/install.sh | sudo bash
```
