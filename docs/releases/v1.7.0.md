## 升级

已安装用户在「系统设置 → 网页更新」检查并更新即可。新用户使用：

```bash
curl -fsSL https://raw.githubusercontent.com/cshaizhihao/OU-YAML/main/install.sh | sudo bash
```

旧订阅链接保持有效。新版本发布的地址支持加密找回；v1.5 及更早地址如需找回，可手动重置一次。请一起备份数据库与 `data/subscription.key`。

代理实测从服务器发起，不代表客户端网速。复杂协议参数需保留客户端验证；第三方 IP 归属地可能有误差。sing-box 不支持的跨格式配置会明确提示，不再静默转换。
