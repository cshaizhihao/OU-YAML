# 💜 OU-YAML v1.9.0

**看清内容，专注编辑，原订阅地址继续使用。**

- 🎨 提升紫色 Liquid Glass 界面的文字、按钮和输入框对比度。
- 📚 中文规则默认显示摘要，点击编辑展开匹配方式、目标策略、说明与英文原文；高级模式仍可用。
- ✅ 单条和批量删除统一确认；规则提醒按需展开，长内容在手机上自动换行。
- 🧩 分组工作台重新分配空间，支持全屏、组嵌套与小屏分区切换。
- ✏️ 已生成订阅编辑页压缩头部，固定发布区域，更新失败保留修改和原内容。
- 📦 节点按钮明确显示「复制节点链接」，TCP 结果紧邻探测按钮，操作区适配不同宽度。
- 🧭 教程遇到弹窗暂时隐藏，小屏为教程预留空间，不遮挡发布按钮；收起的侧栏不参与键盘访问。
- 📱 覆盖 360px、768px、1024px、1440px 布局与真实保存、导出、订阅更新流程。

## 🔄 更新方式

已安装用户：**系统设置 → 网页更新 → 稳定版 → 检查更新**。

新用户：

```bash
curl -fsSL https://raw.githubusercontent.com/cshaizhihao/OU-YAML/main/install.sh | sudo bash
```

应用版本升至 **1.9.0**，保留 V1.0.0 UI 基线标记，不降级版本号。无新增数据库迁移，不改变 API 或导出格式，不更换原订阅地址。更新前建议备份完整 `data` 目录（含 `subscription.key`）。

编辑草稿后仍需检查并发布，再到客户端刷新订阅。TCP 探测仅表示端口可达，不代表代理鉴权或转发成功。
