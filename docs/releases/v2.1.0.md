# OU-YAML V2.1.0 发布通告 (Release Notes)

> **发布版本**: `V2.1.0`  
> **核心主题**: 次时代 Cyber Grid 空间网格、策略组四列响应式看板修复与流光向导交互全面跃升  
> **发布日期**: 2026 年 10 月 15 日  

---

## 💎 版本重大更新摘要

在本次超大幅度的 V2.1.0 更新中，我们通过无头浏览器深入真实部署的测试机现场，逐项审视了每个视图的真实渲染状态，排查并彻底清除了关键排版与视觉缺陷，同时将整个项目的美术质感推向全新高度。

### 1. 策略组四列看板系统彻底修复与重塑 (Groups Kanban Board)
- **彻底根除垂直挤压排版 Bug**：解决了旧版中因缺失看板容器网格样式，导致在部分分辨率下“全部分组”、“当前组成员”、“拖拽手柄”等元素严重错位、挤压成单列的重大缺陷。
- **自适应四列看板架构**：
  - **策略组导航列 (Group Overview)**：240px 专属侧栏，支持上下拖拽微调排序与嵌套拖拽。
  - **核心策略组编辑泳道 (Group Canvas)**：宽敞通透的毛玻璃卡片，支持流畅拖放节点与内置策略（DIRECT/REJECT）。
  - **可编排节点池 (Node Pool)**：直观快速的节点检索、勾选加入与状态统计。
  - **属性检查器 (Group Inspector)**：展示策略组引用关系、规则命中以及嵌套策略快速配置。
- **移动端与窄屏适配**：智能在 Segmented Control 与桌面平铺模式间无缝切换。

### 2. Cyber Grid 纳米空间网格与宇宙深空环境光
- 全局注入 48px 几何纳米空间网格纹理（Cyber Grid Texture）与极光漫射光晕（Aurora Mesh Glow）。
- 告别纯死黑的沉闷与单调，带来 Apple / Linear 级的高奢深曜石纵深空间感。

### 3. 空状态艺术升级与微指标仪表盘 (Empty States & Micro Metrics)
- **同心发光光环 (Radial Glow Ring)**：在订阅来源、节点库、模板管理等空页面中，引入悬浮微动的科技光环微插画与清晰的快捷操作引导。
- **微指标数据胶囊 (Metric Pills)**：采用数字等宽字体排印（`tabular-nums`），指标一目了然。
- **协议霓虹徽章 (Cyber Protocol Badges)**：Shadowsocks, VMess, VLESS, Trojan, Hysteria2, TUIC 配备专业定制的电光高辨识度徽章。

### 4. 新手向导弹窗与侧边栏体验优化
- **流光 Stepper 导轨**：欢迎向导弹窗升级为高通透高斯模糊（`backdrop-filter: blur(14px)`），3 步流程卡片加入发光光圈与悬浮微动效。
- **侧边栏教程入口**：移除突兀的纯黄线框，改用赛博曜石专属的微晶玻璃卡片与天青电光脉冲灯。
- **登录界面高阶流光与规范性**：补齐标准 HTML 语义属性，修复浏览器自动填充黄色底色覆盖，左侧加入 macOS 风格的高级 IDE 代码视窗与版本微徽章。

## 📦 部署与升级指南

对于正在运行 OU-YAML 服务的环境，只需拉取最新镜像或代码重新构建即可：

```bash
git fetch origin main
git checkout main
npm ci
npm run build
systemctl restart ou-yaml
```
